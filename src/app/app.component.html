What the DCC checks

Syntactic / structural only: Required fields, formats, references — no clinical interpretation
Observation & DiagnosticReport: status, code, category, subject, effective/issued, performer, result
Laboratory: LOINC, UCUM, reference ranges, critical values, workflow structure
Gate outcome: PASS → ready for Platform Uploader · FAIL → notify data provider with discrepancies

Privacy: local / on-premise processing, data minimisation, outputs limited to technical findings.

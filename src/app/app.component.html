How this website works

Pick a preset (or upload your own config), load a dataset, run the gate, then export the report. Processing stays on this device.

  1. Choose a validation config Use a website preset (FHIR or SHIELD) or upload JSON / YAML / CSV.
  2. Load your dataset Upload a file, paste JSON/CSV package text, or load a built-in sample.
  3. Fill run context Dataset ID and source/site are stored with the audit report.
  4. Run & export PASS / FAIL plus JSON, Markdown, HTML, or Print / PDF.
